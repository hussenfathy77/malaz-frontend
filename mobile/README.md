# تطبيق ملاذ (Malaz Mobile App) 🌿

تطبيق الموبايل الكامل لمنصة **ملاذ (Malaz)** للصحة النفسية والرعاية التخصصية، مبني باستخدام **React Native (Expo)** ومربوط بالكامل مع الـ Backend والـ API Schema.

---

## 📱 التقنيات المستخدمة
- **React Native 0.88 / Expo SDK 58**
- **AsyncStorage** لحفظ الجلسة والـ Tokens وإعدادات الـ API.
- **Expo Vector Icons** (أيقونات عصرية Ionicons).
- **تصميم متجاوب ومريح نفسياً (Serene Dark Mental-Health Theme)** يدعم اللغة العربية بالكامل (RTL).
- **Fallback Mock Layer مدمجة**: التطبيق يعمل بكفاءة 100% سواء كان سيرفر الباك اند يعمل محلياً أو غير متاح حالياً، مع إمكانية توجيه الـ API Base URL لأي سيرفر بضغطة زر.

---

## 🚀 كيفية تشغيل التطبيق
من داخل مجلد `mobile`:

```bash
cd mobile

# لتشغيل التطبيق على المتصفح (Web Preview):
npm run web

# لتشغيل التطبيق على محاكي الأندرويد (Android):
npm run android

# لتشغيل السيرفر التفاعلي وقراءة كود QR عبر تطبيق Expo Go على هاتفك:
npx expo start
```

## 👥 الأدوار ومراحل التنفيذ (Phases & User Roles)

### 1. مرحلة المصادقة والتسجيل المخصص (Multi-Role Authentication)
- **تسجيل دخول موحد** مع كشف الدور تلقائياً.
- **شاشة إنشاء حساب مخصصة (Custom Registration)** بناءً على متطلبات الباك اند:
  - **مستفيد / مريض (PATIENT)**: تاريخ الميلاد، الجنس، ورقم اتصال الطوارئ.
  - **طبيب / أخصائي نفسي (DOCTOR)**: التخصص، سعر الجلسة، نبذة مهنية، ورابط الشهادات.
  - **مرافق رعاية (CAREGIVER)**: التخويل والموافقة الصريحة.
- **استعادة كلمة المرور** (Forgot & Reset Password).
- **أزرار تجربة سريعة (Demo Accounts)** للانتقال المباشر دون الحاجة لكتابة بيانات في كل مرة.

---

### 2. بوابة المريض (Patient Portal)
- **الصفحة الرئيسية**: مؤشر المزاج السريع، بطاقة موعد الجلسة القادمة، واختصارات الخدمات.
- **مقياس المزاج (Mood Tracker)**: تقييم 1 إلى 10، وسوم المشاعر (هادئ، مجهد، قلق، متفائل)، وسجل التطور الزمني.
- **اليوميات الذكية (Journal & AI Reflection)**: تدوين اليوميات مع تحليل وردود إرشادية ذكية لدعم الاستقرار النفسي.
- **دليل الأطباء والحجز (Doctors Catalog & Booking)**: بحث بالتخصص، استعراض المواعيد، وحجز مع بوابة دفع تجريبية (`/appointments/:id/pay`).
- **إدارة المواعيد (Appointments)**: المواعيد القادمة والمكتملة، رابط الجلسة المرئية، وإمكانية تقييم الطبيب بعد انتهاء الجلسة.
- **دوائر الأمان (Safe Circles)**: الانضمام لمجموعات الدعم وغرف المحادثات التفاعلية.
- **مرافقو الرعاية (Caregivers)**: دعوة مرافقين عبر البريد وتحديد نطاق الصلاحيات.

---

### 3. بوابة الطبيب (Doctor Portal)
- **لوحة معلومات الطبيب**: إحصائيات الجلسات، الحجوزات المعلقة، وتقييم المرضى.
- **جدول أوقات العمل (Working Hours)**: إدارة وتحديد أيام وساعات الاستشارات المتاحة.
- **إدارة مواعيد المرضى**: قبول وتأكيد الحجز، إنهاء الجلسة، وإرفاق روابط الاجتماع.
- **الملاحظات الإكلينيكية (Clinical Notes)**: كتابة وتعديل التشخيص وخطة العلاج وملاحظات الجلسة لكل مريض.

---

### 4. بوابة مرافق الرعاية (Caregiver Portal)
- **متابعة صحة المريض**: مؤشر استقرار نفسي أسبوعي، سجل مزاج المريض، والمواعيد.
- **إدارة الموافقات**: قبول أو إيقاف التخويل لمتابعة المريض.

---

### 5. بوابة الإدارة والإشعارات (Admin & System)
- **توثيق الأطباء**: فحص شهادات وتراخيص الأطباء واعتمادهم لشارة "طبيب معتمد".
- **إدارة حسابات المستخدمين**: تفعيل وتجميد الحسابات.
- **مركز الإشعارات**: متابعة التنبيهات مع تحديد المقروء.
- **شريط التبديل السريع (Role Switcher Bar)**: شريط علوي يتيح لك تجربة الأدوار الأربعة بلمسة واحدة.
